关于博客

这是一个个人博客，用于记录阅读时、日常生活中的思考，以及一些平日里折腾的零零碎碎的小玩意。感谢ai让我一个小白也能做些以前一直做不了的东西，之后可能会慢慢学习修改，就酱紫吧。

技术栈

本博客是一个纯静态网站，使用 HTML + CSS + JavaScript 构建。文章通过 Markdown 编写，使用 marked.js 渲染。无需服务器或数据库，可部署到任何静态托管平台。
