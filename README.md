# 浊酒澄心的博客

> 遥祝远行人 有道不孤

一个使用纯 HTML/CSS/JS 构建的个人静态博客，设计语言借鉴《明日方舟》官网的工业机能风格。

## 技术栈

- **HTML5 + CSS3 + Vanilla JavaScript** — 无框架，无构建工具
- **Markdown 渲染** — 文章通过 [marked.js](https://github.com/markedjs/marked) 在客户端渲染
- **纯静态部署** — 无需服务器或数据库，托管于 GitHub Pages

## 特性

- 深色 / 日间双主题切换，支持跟随系统偏好
- 毛玻璃卡片 + 噪点纹理 + 几何装饰
- 响应式布局，适配桌面端与移动端
- 标签筛选、全文搜索
- 本地管理后台（`admin.html`，密码保护）
- 文章通过 Markdown 编写，所见即所得预览
- Open Graph 元标签，支持社交分享预览

## 本地使用

直接在浏览器中打开 `index.html` 即可。管理后台通过 `admin.html` 访问。
